# 此刻 · CIKE

**把注意力，交还给自己。**

一个轻量的中文注意力小工具：把大目标拆成现在能开始的一小步，也为主动休息留出位置。

## 三个核心功能

- **拆出下一步**：输入目标和当前精力，得到一个带结束条件的小行动。可以修改内容与时长，也可以继续拆小。
- **只做这一件**：开始、暂停或手动完成当前行动。到点只是一次回看提醒，不会自动判定完成，不会自动开始下一轮。
- **休息与再选择**：随时休息，保留中途暂停的行动；根据进展和精力，再选择继续、拆小或结束。

另有方向管理、分心念头暂存、行动与休息记录、反馈笔记、备份导出和记录导出。没有排行榜、连续打卡或完成量要求。

## 直接使用

仓库根目录的 `index.html` 就是完整工具。下载后用 Chrome、Safari 或 Edge 打开即可，无需安装依赖或登录。

开启 GitHub Pages 后，也可以通过网页地址使用。进入仓库 **Settings → Pages**，选择 **Deploy from a branch**，发布来源为 **main / (root)**。

## 数据和隐私

- 目标、行动、精力、笔记和记录保存在当前浏览器的 `localStorage` 中。
- 不上传个人记录，不收集分析数据，不调用在线 AI，不会在设备间自动同步。
- 浏览器、设备和网站地址不同，保存空间也不同。迁移前请先导出完整备份。
- 清理浏览器数据或使用无痕模式可能导致记录丢失，请定期备份。
- 关闭页面期间不会发出通知；重新打开时，已到点的行动停在回看状态。

**行动建议使用本地模板**，按目标关键词与自报精力匹配，涵盖写作、学习、产品与方案、整理、活动和通用目标。它是可编辑的起点，不会理解完整项目背景。约 10 分钟只是帮助开始的尺度。

## 开发

纯 HTML、CSS 和 JavaScript，无运行时依赖。开发时可直接打开 `src/template.html`，或在仓库目录启动一个静态文件服务器。

```sh
python3 -m http.server 8000
```

打开 `http://localhost:8000/src/template.html` 查看源文件版本。

修改 `src/` 后重新生成单文件版本：

```sh
python3 build.py
```

输出包括根目录 `index.html`、本地单文件版及使用包。发布更新时，将新的 `index.html` 与源文件一起提交。

核心逻辑测试使用 Node.js 内置测试工具：

```sh
node --test tests/core.test.cjs
```

## 文件结构

```text
index.html             可直接使用和发布的完整工具
src/template.html      开发入口
src/styles.css         页面样式
src/core.js            行动建议与计时状态
src/app.js             界面和本地保存
tests/core.test.cjs    核心流程测试
build.py               生成独立使用版
使用说明.md            日常使用说明
```

任务、计时和主动休息的组织思路参考 [Super Productivity](https://github.com/super-productivity/super-productivity)。本工具代码独立实现。
